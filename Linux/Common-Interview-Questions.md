## What is the root directory in Linux?
- The root directory (/) is the top-most directory from which all other directories originate

## Difference between /bin and /sbin?
1. /bin
- User commands
- Accessible by users
2. /sbin
- System administration commands
- Mainly for administrators

## What is /proc?
- A virtual filesystem containing information aboutrunning processes and kernel parameters.

## Where are user files stored?
- Inside /home/<username>

## Where are Linux logs stored?
- /var/log
