# Linux Basics

## Linux Distributions
- an OS built on Linux kernel bundled with essential softwares, tools, and package managers, customized for each users

1. Ubuntu
- most widely used distribution
Features:
- Easy installation
- Long term support versions
- Large software repositories

2. Kali Linux
3. Debian
4. Arch Linux
5. CentOS Stream
6. Linux Mint

## Components of Linux Distribution
1. Linux kernel
- core of the OS
- manages the hardware resources, control system processes, memory management
- bridge between hardware and user applications

2. System Libraries and Utilities
- These libraries are essential for running programs and executing system calls effectively.
- GNU C Library(glibc) - provides standard functions and APIs

3. User Interface (UI)
- Graphical User Interface(GUI) - GNOME, KDE, Xfce provide a user-friendly visual environment for interacting with the system
- Command-Line Interface(CLI) - offers direct control of the system through terminal commands.

4. Software Packages
- tailored for productivity tools, Web browsers, Media players, Development tools

5. Package Management System
6. Configuration and Customizatin
7. Support and Community

## Benefits of using Linux
1. Cost-free and Open Source
2. Customization
3. Security
4. Resource-Efficient
5. Development and Programming
6. Stability and Reliability
