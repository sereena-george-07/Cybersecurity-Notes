## What is the main purpose of OSI Model?
To standardize communication functionsand simplify network troubleshooting

## Which OSI layer is responsible for routing
Network layer (Layer 3)

## Which OSI layer uses MAC addresses?
Data Link Layer (Layer 2)

## Which protocols operate at the Transport Layer?
TCP and UDP

## Which model is used on the Internet?
TCP/IP Model

## Why is the OSI model important?
It helps understand how data moves through a network and assists in troubleshooting networking issues.
